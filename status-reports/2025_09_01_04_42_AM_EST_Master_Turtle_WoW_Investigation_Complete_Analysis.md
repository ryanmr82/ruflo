- **UE5 Project:** Turtle WoW 2.0 using Unreal Engine 5 (announced July 2024)

### Technical Complexity: The Open Source Foundation Defense

#### vMaNGOS: The Legitimate Open Source Base
**Core Defense Argument:** Turtle WoW is built on vMaNGOS, a completely legal, GPL-licensed open source server emulation platform.

**Key Technical Facts Supporting Defense:**
- **vMaNGOS License:** GNU General Public License (GPL) v2 or later - completely legal for use, modification, and distribution
- **Reverse Engineering Protection:** Created through legal reverse engineering methods, protected under Sony v. Connectix and Sega v. Accolade precedents
- **No Blizzard Code:** vMaNGOS contains zero lines of Blizzard's proprietary code - complete clean-room implementation
- **Educational Purpose:** Explicitly positioned as educational project for learning server architecture

#### Legal Precedent Supporting Open Source Defense

**Sony Computer Entertainment v. Connectix Corp. (2000):**
- Court ruled that copying copyrighted BIOS software during emulator development does not constitute copyright infringement when covered by fair use
- Established that reverse engineering for interoperability falls under fair use

**Sega v. Accolade (1992):**
- Ninth Circuit ruled that reverse engineering to publish compatible software was protected under fair use
- Established that functional principles are not protected by copyright when no other means are available

#### Separation of Server Code vs. Client Assets
**Critical Legal Distinction:** The server emulation software (which Turtle WoW operates) contains NO copyrighted assets:
- No graphics, sounds, 3D models, textures, or logos
- Only mathematical algorithms and network protocols  
- Users must provide their own legitimate WoW client installation

**Defense Position:** "We provide a calculator; users provide the numbers to calculate."

- **No Blizzard Code:** vMaNGOS contains zero lines of Blizzard's proprietary code - complete clean-room implementation
- **Educational Purpose:** Explicitly positioned as educational project for learning server architecture and game development

#### Established Legal Precedent Supporting Defense

**Sony Computer Entertainment v. Connectix Corp. (2000):**
- Federal court ruled that copying copyrighted BIOS software during emulator development does not constitute copyright infringement when covered by fair use
- Established legal principle that reverse engineering for interoperability falls under fair use protection
- Precedent directly applicable to server emulation technology

**Sega v. Accolade (1992):**
- Ninth Circuit Court of Appeals ruled that reverse engineering to publish compatible software was protected under fair use
- Established that functional principles are not protected by copyright when no other means are available
- Created legal framework for legitimate reverse engineering operations

### Critical Legal Distinction: Server vs. Client Architecture

**Separation of Server Code vs. Client Assets:**
The server emulation software operated by Turtle WoW contains NO copyrighted assets:
- **No Visual Assets:** No graphics, sounds, 3D models, textures, or logos
- **Functional Elements Only:** Only mathematical algorithms and network communication protocols
- **User Responsibility:** Users must provide their own legitimate WoW client installation
- **Legal Analogy:** "We provide a calculator; users provide the numbers to calculate"

#### Technical Architecture Defense
**Clean-Room Implementation Benefits:**
- **Independent Development:** vMaNGOS developed independently without access to Blizzard source code
