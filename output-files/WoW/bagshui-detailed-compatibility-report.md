- **Latest Version:** v1.5.11 (August 2025)

- **Maintenance:** Active with 503+ commits
- **Developer:** Responsive to bug reports

### Known Current Issues (2024-2025)

1. **Tooltip Errors** (Partially Fixed)
   - Pressing Alt near top of screen causes blank tooltips
   - Error in Tooltips.lua line 314
   - More noticeable on 4K monitors
   - Developer aware and working on fix

2. **Direct Assignment Bugs** (Acknowledged)
   - "Serious bugginess" with custom category assignment
   - Developer confirmed issues in January 2025
   - Fix promised in future update

3. **MinimapButtonBag Conflict** (FIXED in v1.0.5)
   - Icon corruption issue
   - Auto-collapse broken
   - **Already fixed** - just update to latest

4. **NO "Grayed Out Items" Bug**
   - Unlike Cleanup/SortBags
   - Items don't get stuck
   - This is a major advantage

## My Honest Recommendation

### ⚠️ **PROCEED WITH CAUTION**

**Bagshui is the best bag addon available for Turtle WoW, BUT:**

1. **It has active bugs** being worked on
2. **It's complex** and may frustrate you
3. **No guarantee** of perfect compatibility with your setup
4. **Still better** than buggy Cleanup/SortBags

### Suggested Approach:

1. **Try it with backup ready:**
   - Install Bagshui
   - Test for 30 minutes
   - If issues, remove it

2. **Start simple:**
   - Use basic features only
   - Avoid Direct Assignment
   - Configure gradually

3. **Have realistic expectations:**
   - It's not perfect
   - Bugs exist
   - Developer is fixing them
