AtlasLoot Recipe Extractor Package Contents
============================================

This package contains everything needed to extract crafting recipes from AtlasLoot.

📁 Files Included:
------------------

1. ATLASLOOT_EXTRACTION_GUIDE.md (Complete Guide)
   - Step-by-step instructions
   - Prerequisites and setup
   - Troubleshooting section
   - Technical details
   - FAQ

2. QUICK_START.md (Quick Reference)
   - 1-page quick start guide
   - Essential steps only

3. atlasloot_final_parser.py (Working Script)
   - Ready-to-use Python script
   - Just edit 3 lines at the top
   - Extracts all recipe data with materials

4. tailoring_COMPLETE.md (Example Output - Markdown)
   - Human-readable documentation
   - All 406 Tailoring recipes
   - Includes skill requirements and materials

5. tailoring_COMPLETE.json (Example Output - JSON)

   - For programming/scripting

6. tailoring_COMPLETE.csv (Example Output - CSV)
   - Spreadsheet format
   - Open in Excel/Google Sheets

📋 Quick Start:
--------------

1. Read ATLASLOOT_EXTRACTION_GUIDE.md first
2. Install Python 3.x (if not already installed)
3. Edit atlasloot_final_parser.py (lines 18-20):
   - Set WOW_FOLDER to your WoW installation path
   - Set PROFESSION to desired profession
   - Set OUTPUT_FOLDER where you want files saved
4. Run: python atlasloot_final_parser.py
5. Get your recipe documentation!

🎯 What This Extracts:
---------------------

For ANY profession (Tailoring, Blacksmithing, Alchemy, etc.):
- Recipe names and quality
- Skill requirements (Orange/Yellow/Green/Gray)
- Material requirements (item IDs and quantities)
- Crafting times
- Tools required
- Crafted item IDs
