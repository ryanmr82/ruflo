🚀 HOW TO USE (SUPER EASY):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: C:\turtlewow\Logs\
2. Double-click: start_web_app.bat
3. Browser opens automatically!
4. Fill out the form:
   - Player Name: YourCharacterName
   - Raid: MC (or BWL, AQ40, etc.)
   - Start Time: 10/20/2025 4:00 PM
   - End Detection: Auto-detect ✓
5. Click "Process Combat Log"
6. Download the ZIP file
7. Upload to Legacy Logs!


✨ WHAT IT DOES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Extracts ONLY your raid timeframe (not the entire log!)
✓ Auto-detects when boss dies
✓ Formats for Legacy Logs upload
✓ Archives your original logs
✓ Creates fresh logs for next raid
✓ One-click download

⚠️ TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Flask not found"
Fix:     Open command prompt in Logs folder and run:
         pip install -r requirements.txt

Problem: "Python not found"
Fix:     Install Python from python.org
         Make sure to check "Add to PATH" during install!

Problem: "Web page won't load"
Fix:     Manually go to: http://localhost:5000

Problem: "No boss death detected"
Fix:     Switch to "Manual" and enter end time yourself


💡 TIPS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Process logs RIGHT after raid (while times are fresh)
• Auto-detect works best for full clears
• Use manual mode if you didn't kill final boss
• Keep at least 2-3 archived logs as backup
• Read QUICK_START_CARD.txt for more details
