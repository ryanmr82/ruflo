# AtlasLoot Tailoring Recipes Documentation

**Source:** Turtle WoW - AtlasLoot Addon

**Note:** This documentation shows skill requirements and progression. For material requirements, you can look up each recipe by spell ID on sites like:
- [Turtle WoW Database](https://database.turtlecraft.gg/)
- [Classic WoW Database](https://classic.wowhead.com/)

## Understanding Skill Levels

- **Orange:** Guaranteed skill point gain
- **Yellow:** High chance of skill point gain
- **Green:** Low chance of skill point gain
- **Gray:** No skill point gain (recipe is trivial)
