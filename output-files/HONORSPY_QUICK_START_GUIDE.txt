TESTING INSTRUCTIONS
================================================================================

1. LAUNCH WOW
   - Start World of Warcraft
   - Log in to any character

2. ENABLE ERROR DISPLAY
   /console scriptErrors 1

3. OPEN HONORSPY
   /honorspy show
   (or use the minimap button)

4. CHECK PERSONAL STATS DISPLAY (NEW!)
   - At the top you should see:
     ═══ YOUR STATS ═══
     Rank X              Bar: XX%
     Rank Points:        XXXXX RP
     Standing:           #XXX (Bracket X)
     This Week Honor:    XXXXXX
     Last Week Honor:    XXXXXX
     ═════════════════════════

   - MOST IMPORTANT: "Bar: XX%" shows your rank progress!
   - This number moves each week based on your bracket
   - Track this weekly to see your progress

5. TEST COLUMN SORTING
   - Click "Name" column header → Should sort A-Z
   - Click "Name" again → Should sort Z-A (notice ▲ or ▼ indicator)
   - Try each column:
     * Name
     * ThisWeekHonor
     * LastWeekHonor
     * Standing
     * Rank Points (formerly "RP")
     * Rank

6. TEST SCROLLING (if list has 100+ entries)
   - Normal mousewheel → Scrolls 1 line
   - Shift+Mousewheel → Scrolls 5 lines (faster!)
   - Look for scroll buttons (may show at edges)

7. VERIFY NO LUA ERRORS
   - If red error text appears, screenshot it
   - Check error mentions HonorSpy or Tablet

================================================================================
KNOWN LIMITATIONS
================================================================================

NO VISUAL DRAGGABLE SCROLLBAR:
  - Tablet-2.0 library doesn't support it natively
  - Would require modifying 2000+ line library
  - Risk of breaking 5+ other addons
  - Alternatives implemented instead (Shift+Mousewheel, scroll buttons)

SCROLL BUTTONS MAY NOT SHOW:
  - Depends on Tablet-2.0 frame lifecycle
  - Mousewheel scrolling is primary method
  - Buttons are bonus feature if they work

SORT LIMITED TO CURRENT VIEW:
  - Sorts visible entries only
  - If using "Limit Rows" option, only those rows sorted
  - For full sort, remove row limit (/honorspy options)
