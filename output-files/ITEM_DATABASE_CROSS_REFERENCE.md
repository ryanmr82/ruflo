## Juju Tracking Fix - VERIFIED

**Problem:** Jujus were not showing up in the juju column.

**Root Cause:** Regex pattern `r'(\w+) uses (.+?)\.'` captured "Juju Power on Veryheavy" instead of just "Juju Power" because jujus use the pattern:
```
PlayerName uses Juju Power on PlayerName.
```

**Fix Applied:** Changed regex to `r'(\w+) uses (.+?)(?:\son\s|\.)'` to stop at either " on " or "."

**Verification:**
- **Log contains:** 76 juju uses (Power:36, Flurry:18, Might:13, Ember:9)
- **Analyzer now tracks:** 88 jujus total
  - Juju Power: 36 ✅
  - Juju Flurry: 18 ✅
  - Juju Might: 13 ✅
  - Juju Ember: 9 ✅
  - Spirit of Zanza: 12 ✅ (bonus tracking)

**Status:** ✅ ALL jujus now properly tracked with item IDs cross-referenced
