## What's Next

### First Launch Steps
1. Launch Turtle WoW
2. At character select: Check AddOns menu
3. Verify "BananaBar Raid Symbols" is enabled
4. Enter game world
5. Type `/bb` to open configuration
6. Position buttons (Ctrl+Right-Click to move)
7. Configure settings to your preference

### Commands to Remember
- `/bb` - Open config menu
- `/bbtarget 1-8` - Target by symbol (for macros)
- Left-Click button - Target marked unit
- Ctrl+Left-Click - Set/remove symbol
- Ctrl+Right-Click - Move buttons
